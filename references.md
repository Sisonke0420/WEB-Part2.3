# References

## Design and typography

1. Google Fonts  
   https://fonts.google.com/
   - Used for the Fraunces and Red Hat Display typefaces.

2. MDN Web Docs — CSS  
   https://developer.mozilla.org/en-US/docs/Web/CSS
   - Used for layout, color, spacing, and responsive styling guidance.

3. MDN Web Docs — HTML  
   https://developer.mozilla.org/en-US/docs/Web/HTML
   - Used for semantic page structure and accessibility best practices.

4. W3C HTML Living Standard  
   https://html.spec.whatwg.org/
   - Used as a reference for standard HTML semantics and document structure.

5. WAI-ARIA Authoring Practices  
   https://www.w3.org/WAI/ARIA/apg/
   - Used for reference patterns around navigation and button interaction.

6. MDN Web Docs — JavaScript  
   https://developer.mozilla.org/en-US/docs/Web/JavaScript
   - Used for DOM manipulation, event handling, and interaction logic.

8. Modern charity and nonprofit landing page layouts  
   Inspiration for a clean editorial style, strong headline hierarchy, and clear calls to action.
